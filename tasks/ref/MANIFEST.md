Generated by `scripts/refcards/manifest.py`. Per-task detail: `MANIFEST.json`. No human text is published here: each task records its dataset, record locator and date so the text can be retrieved from the source. Names and details in the tasks are the source's own; the tasks are not anonymised.

## Checking a text you retrieved

Every active task has `text_sha256` in `MANIFEST.json`: the SHA-256 of the human text as the benchmark stores it, which is the source text in UTF-8 with leading and trailing whitespace removed and one newline added at the end. 19 active tasks also name the dataset revision and the record's position in it. The other 38 come from files downloaded without a pinned revision (a first batch, taken before revisions were recorded); for those, `raw_downloads` gives each file's size, SHA-256 and retrieval date, and `experiments/judge_cpu/README.md` says what each file is. If a source file has changed since, the record locator may point elsewhere, and the text hash is the check that you have the right piece.
